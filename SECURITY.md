# Política de segurança

Não publique vulnerabilidades, credenciais ou dados pessoais em issues públicas. Para relatar uma falha de segurança, entre em contato com o mantenedor por um canal privado e informe uma descrição reproduzível, o impacto e, se possível, uma sugestão de correção.

O projeto ignora arquivos de ambiente, bancos locais, logs e artefatos de build. Ainda assim, cada contribuição deve ser revisada para evitar a inclusão acidental de segredos.
